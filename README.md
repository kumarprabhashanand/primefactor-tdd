# primefactor-tdd

The classic prime factors kata, done test-first with JUnit 5: write a failing test, make it pass, refactor, repeat.

Companion code for my article [TDD: Test Driven Development with Java and JUnit](https://medium.com/@kumarprabhashanand/tdd-test-driven-development-with-java-and-junit-e82a6f1cef47).

- `src/PrimeFactorTest.java` - the tests, in the order they were written
- `src/PrimeFactor.java` - the code that made them pass

Open it in your IDE and run `PrimeFactorTest`.
